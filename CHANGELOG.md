## [0.1.0] - 2026-05-13

### Added
- Initial release
- 6-axis benchmark profile: persona stability, inverse accessibility, hysteresis,
  cross-domain transfer, internal shift, compression ratio
- 5 persona pairs (helpful_assistant, truthful_scientist, cautious_medical,
  constitutional_ai, non_anthropomorphic)
- 7 procedurally generated perturbation categories
- Anthropic and OpenAI-compatible API support
- 6-state keyword-based behavioral classifier
- CLI with radar profile output and JSON export
